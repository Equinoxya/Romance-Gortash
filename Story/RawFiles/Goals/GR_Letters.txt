// Gortash Romance - delivery of the letters and gifts.
//
// Each letter is handed to the player at the first long rest after its
// trigger. Base game references, found in the game's own story scripts:
//
//   WYR_KillDirectorGortash_State_AfterCeremony   set when the coronation dialogue
//                                                 ends (Act3_WYR_KillDirectorGortash)
//   EPI_Epilogue_State_PartyGameplayStarted       set when the reunion party starts
//                                                 (Act3c_EPI_MainEpilogue; Gale, Wyll
//                                                 and Astarion react to it the same way)
//   REALLY_DARK_URGE                              Dark Urge tag the game checks on players
//   FEMALE / IDENTITY_NEUTRAL                     identity tags (used the same way in
//                                                 Act3b_LOW_OskarsBeloved); MALE is the default
//   ParentTargetEdge "Act3"                       same parent as Act3_WYR_WyrmRock
//
//   Mod items and flags are written as Name_UUID. They are generated
//   by tools/build_toolkit.py, which also fills them here (--osiris).
//
// LongRestFinished, TemplateAddTo, SetFlag, IsTagged and FlagSet are used with
// the same signatures in the game's scripts. Not compiled yet.

//REGION Step 2 - office evening, staged in Gortash's office
// Closing the invitation letter starts GR_Office_Invitation: go tonight, or not.
// "Not tonight" sets nothing, so reading the letter again offers the choice again.
// "Tonight" sets GR_Office_Visited: fade to black, Gortash is moved to his place in his
// office and the player, alone, next to him (from camp, the party first travels to
// Wyrm's Rock), then
// GR_Office_Evening plays there with its timeline. Afterwards Gortash goes back to the
// Morphic Pool if that is where he was; the player stays in the office.
// Game objects and calls, as Act3_WYR_KillDirectorGortash uses them:
//   S_WYR_GortashsPositionInOffice, S_Debug_Teleport_WYR_GortashsOffice,
//   S_END_MorphicGortashPoint, WYR_KillDirectorGortash_Event_TeleportedToUndercity.
//   ScreenFadeDone gives a user id, not a character: the player comes from our database.
// The three invitation letters (one per identity). A query rather than an INIT
// database, so that it also works in saves where this goal was already running.
QRY
QRY_GR_IsInvitationLetter((ROOT)_Template)
AND
_Template == GR_Letter_Invitation_04f0d615-092d-418a-95a4-358a2e3ea0c1
THEN
DB_NOOP(1);

QRY
QRY_GR_IsInvitationLetter((ROOT)_Template)
AND
_Template == GR_Letter_Invitation_F_6c1d0f3e-5b7a-4e21-9a44-1f0b7d2c8e51
THEN
DB_NOOP(1);

AND
_Template == GR_Letter_Invitation_NB_b2e4a9d7-3c58-4f06-8d1a-7e9c25f4a063
THEN
DB_NOOP(1);

AND

AND

AND

AND
RealSum(_GX, _SX, _NX)
AND

THEN

AND
